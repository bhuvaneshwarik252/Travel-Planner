# ✅ Part 1 — Simple High-Level Steps

## 🟢 Phase 1 — Build Application

1. Choose language (Node.js / Python / Java — anything is fine)

3. Connect to **MySQL database**
4. Implement **CRUD APIs** (Create, Read, Update, Delete)

---

## 🟡 Phase 2 — Containerization

5. Write **Dockerfile**
6. Build Docker image
7. Test container locally
8. Push image to Docker Hub (or registry)

---

## 🟠 Phase 3 — Kubernetes Setup

9. Install K8s cluster

   * Minikube (easiest)
   * Kind (good for local practice)
   * kubeadm (advanced)

---

## 🔵 Phase 4 — Deploy Application in K8s

10. Create Deployment YAML
11. Create Service YAML
12. Deploy to cluster
13. Test via NodePort / LoadBalancer

---

## 🟣 Phase 5 — Persistence (Very Important)

14. Create StorageClass
15. Create Persistent Volume (PV)
16. Create Persistent Volume Claim (PVC)
17. Attach PVC to MySQL Pod

---

## 🟤 Phase 6 — Helm Automation

18. Create Helm Chart
19. Template Deployment + Service + PVC
20. Deploy using Helm install

---

## ⚪ Optional Advanced
